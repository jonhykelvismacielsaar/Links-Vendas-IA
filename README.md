# 🛒 Links Vendas IA — Site de links para a bio do Instagram

Um site simples, rápido e bonito (estilo Linktree) com todos os produtos que você indica nos vídeos.
A pessoa clica no link da sua bio → cai neste site → toca num produto → compra no Mercado Livre pelo seu link de afiliado. ✅

**🌐 Site no ar (depois de publicar):** https://jonhykelvismacielsaar.github.io/Links-Vendas-IA/

---

## ▶️ Como colocar no ar (GitHub Pages — grátis, 1x só)

1. Entre no repositório no GitHub: https://github.com/jonhykelvismacielsaar/Links-Vendas-IA
2. Clique em **Settings** (Configurações) → no menu lateral, **Pages**
3. Em **Build and deployment → Source**, escolha **Deploy from a branch**
4. Branch: **`main`** • Pasta: **`/ (root)`** → clique em **Save**
5. Aguarde 1–2 minutos e abra: **https://jonhykelvismacielsaar.github.io/Links-Vendas-IA/**

> 💡 Se o link já tiver sido ativado para você, pule esta etapa e vá direto para o Instagram.

## 📸 Como colocar o link no Instagram

1. Abra o Instagram → seu **perfil** → **Editar perfil**
2. Em **Links** → **Adicionar link externo**
3. URL: `https://jonhykelvismacielsaar.github.io/Links-Vendas-IA/`
4. Título: `🛒 Produtos que eu indico` → **Salvar** ✅

Pronto! Nos vídeos é só falar: *"link na bio"* 🎬

---

## ➕ Como adicionar produtos novos

**Jeito fácil:** manda aqui no chat no mesmo formato de sempre (nome do produto + link do Mercado Livre) que eu atualizo o site para você. 🤖

**Jeito manual:** edite **apenas** o arquivo [`produtos.js`](produtos.js) — está tudo comentado em português.
Copie um bloco, troque `nome`, `descricao`, `link` e `categoria`. Categorias novas aparecem sozinhas nos filtros.

| Arquivo        | Pra que serve                                  |
|----------------|------------------------------------------------|
| `produtos.js`  | ⭐ Lista de produtos, nome da loja e Instagram |
| `index.html`   | Estrutura da página                           |
| `style.css`    | Visual (cores, fontes, layout mobile)         |
| `script.js`    | Busca, filtros e botão compartilhar           |
